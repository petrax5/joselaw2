# JAH Law Website Redesign

Responsive static redesign for the Law Office of José Alfredo Hernández, A.P.C.

Includes 11 English pages and matching complete Spanish pages under `/es/`. The language switcher now changes the entire page, including headings, paragraphs, service lists, FAQ answers, forms, resource descriptions, calls-to-action, footer and navigation.

UX features:
- Large accessible controls and typography
- Mobile persistent Call button
- tel/mailto links
- One-tap Google Maps directions
- Browser autofill for name/phone/email
- Responsive navigation
- FAQ accordions
- Full English/Spanish page versions
- Original website imagery referenced from existing Wix media URLs

The consultation form is a front-end demo and should be connected to a secure intake/form service before production.
